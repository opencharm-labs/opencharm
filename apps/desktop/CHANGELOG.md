# Changelog

## 0.1.0 (2026-10-03)

The first release of the desktop charm, a GitHub pre-release built by CI (unsigned, with checksums and build attestations).

- OpenCharm under your Mac's notch (on Windows, a pill at the top of the screen), the same firmware core as the charm.
- Hold the talk key to speak; settings for the agent's folder, the charm's look and voice.
