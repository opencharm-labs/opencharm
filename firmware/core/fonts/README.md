# fonts

Sources for the LVGL bitmap fonts in `../src/ui/fonts/` (generated by `npm run firmware:fonts`; never edit the `.c` files).

| File                           | Use                                | Licence                                                                                  |
| ------------------------------ | ---------------------------------- | ---------------------------------------------------------------------------------------- |
| `GeistMono-ExtraBold.ttf`      | face glyphs, pairing digits        | SIL OFL 1.1 (`OFL-Geist.txt`), [vercel/geist-font](https://github.com/vercel/geist-font) |
| `GeistMono-Medium.ttf`         | text lines, PIN pad, hints         | SIL OFL 1.1 (`OFL-Geist.txt`)                                                            |
| `NotoSansSymbols2-Regular.ttf` | only `♥` (Geist Mono has no heart) | SIL OFL 1.1 (`OFL-Noto.txt`), [google/fonts](https://github.com/google/fonts)            |
